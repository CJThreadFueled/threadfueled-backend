📡 **API ENDPOINTS**

Admin:
  POST /api/admin/upload          - Upload new project
  GET  /api/admin/projects        - Get all projects
  GET  /api/admin/projects/:id    - Get specific project
  DELETE /api/admin/projects/:id  - Delete project

Customer:
  GET  /api/customer/project/:code     - Get project by code
  POST /api/customer/approve/:code     - Approve artwork
  POST /api/customer/modify/:code      - Request modifications
